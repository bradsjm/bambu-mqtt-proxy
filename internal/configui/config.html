AI detection

Optional print-failure detection through OctoEverywhere's Gadget service, and an optional build-plate check at print start through a vision model provider.

Gadget AI
Checks camera snapshots of active prints on P1P, P1S, A1, and A1 mini, and can warn or pause a likely failure. The AI badge on a camera wall tile turns detection off for the current print only; this switch controls all printers.
From octoeverywhere.com. With detection on, the proxy uploads camera snapshots from active prints to OctoEverywhere's servers and can slow a print to Silent or pause it without asking. Turn detection off to keep every image local.
Test Asks OctoEverywhere to create one context, proving the key works. No images are uploaded; the provider may associate this key with your public IP.
Vision checks
When a print starts, the proxy uploads one current camera snapshot to the selected provider. If the chamber light is off, the proxy turns it on for the snapshot. If the plate looks occupied above the cutoff, the proxy sends Stop to the printer without asking. If the check fails or the view is unclear, the print continues. This is a best-effort check at print start, not a safety interlock.
Cloudflare runs the plate-check models on Workers AI. Custom sends requests to your own HTTPS endpoint, which must accept the same request and answer format.
