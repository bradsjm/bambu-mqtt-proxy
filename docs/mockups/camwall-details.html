Shared visual vocabulary

How the requests are applied

  1. Stage colors · off gray, heating orange, at temperature red, cooling blue, chamber ambient light gray.
  2. Microcharts · target bullet bars, segmented layer bar, sparklines, ▲▼ trend, fan bars, Wi-Fi bars, AI history.
  3. No resizing · every number sits in a reserved, right-aligned, tabular box (toggle “Show reserved value boxes”, then “Simulate live values”).
  4. Units everywhere · °C, %, h/m, g, m, mm, dBm.
  5. One divider style per Level 3 option; every section uses it, including the first.
  6. AMS · one SVG drawing for every AMS model, external spool drawn with the same spool.
  7. State-aware header · see the Level 1 matrix: each state promotes different facts.
  8. No duplication · layer only in the header; current AI confidence only on the camera (Level 3 keeps its history); job name only in the header; stage only in the camera pill.
  9. Speed · three replacements for the native select, all built from existing chip/segment styles.
  10. Time left sits with its end time · “1h 16m left → 12:35 PM” is one unit; start/elapsed sit together in Level 2.
